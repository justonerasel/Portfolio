# Futuristic Portfolio — Editable Static Website

## What is included
- Responsive one-page portfolio
- Futuristic dark/neon visual style inspired by the supplied references
- Scroll reveal animations
- Animated glowing ring and floating cards
- Mobile navigation
- Project cards, skills, about and contact sections
- No framework or build step required

## How to customize
1. Open `index.html` and change your name, text, project names, links and social URLs.
2. Replace `assets/images/profile-placeholder.svg` with your photo. Keep the filename or update the `<img src>` in `index.html`.
3. Edit `assets/css/style.css` to change colors, spacing, typography and layout.
4. Edit `assets/js/main.js` to change interactions/animations.
5. Put your CV at `assets/YOUR-CV.pdf` or change the CV link in `index.html`.

## Upload
This is a normal static website. You can upload the whole folder/repository to:
- GitHub
- Vercel
- Netlify

No database or server is required for the current version.

## Important
The project uses Google Fonts from a CDN. If you want it completely offline, download the fonts and place them in `assets/fonts/`, then update the CSS.
